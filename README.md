# Five Property Manager

A browser-based property management system for managing 5 properties.

## Open The System

Open this file in a browser:

`index.html`

The app saves changes in the browser with local storage. That means records stay on the same computer and browser after refresh.

## Included In This Version

- Portfolio dashboard
- 5 sample properties
- Property records
- Tenant records
- Rent payment tracking
- Maintenance board
- Expense tracking
- Document records
- Reports by property
- Settings
- Editable forms for all main records

## Suggested Next Upgrade

The next version should add a real backend database, secure login, file uploads, tenant accounts, and email or SMS notifications.
